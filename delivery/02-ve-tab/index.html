# 交互与动效

机内角标：

| # | 表面 | 这条动效 |
| --- | --- | --- |
| 1 | VE-Tab | 切换时灰底、文案、行平移同一拍 |
| 2 | Filter List | 拖拽跟手改大小，松手再吸附 |

Toast 不打角标，不走 560ms。

---

## 共用

Tab 与 Filter **共用**一套参数，原生不要拆成两套 ease。

| | |
| --- | --- |
| 时长 | **560ms** |
| 曲线 | `cubic-bezier(0.25, 0.72, 0.22, 1)` |
| 用途 | Tab 切换、文案展开/收起、灰底平移改宽、Filter 松手吸附 |

拖拽过程中 Filter **没有**过渡：位移和大小都跟手，松手后才用上面这套吸附。

---

## 1 · Tab 切换

触发：点某个可点的 Tab（或 Filter 拖进另一分组）。

同时发生、同一条 560ms 曲线：

| 元素 | 做什么 |
| --- | --- |
| 灰色 pill | `x` + `width` 跟到目标 hug 框（min 110 / max 140） |
| 目标项 | 文案 `0fr → 1fr`、间距 0→6、opacity 0→1 |
| 离开项 | 反向收起 |
| 行 | 仅当选中项会被裁切时 `translateX` |

文案宽度必须用可插值轨道（`0fr ↔ 1fr`）。先打开过渡再切选中态。连点时灰底从当前在播的位置接到新目标。

无 Recents 内容时点 Recents：只出 Toast，不要播这条。

---

## 2 · Filter 跟手

拖拽中：位移和大小 1:1 跟手，**关掉** size 过渡。第 `i` 项缩小、第 `i+1` 项放大，其余 `k=0`。跨分割槽时一格是 120px。

松手：用位移+速度估 `projectedX = x + v * 160`，吸附到该 index，`k → 1`，560ms 同 Tab 曲线。

拖过分组边界时，角标 1 的 Tab 切换同步播。

参数

时长560ms。Toast 不要用这条。
曲线cubic-bezier(0.25, 0.72, 0.22, 1)

角标

  • 1

    点 Tab：灰底平移改宽、文案 0fr↔1fr、必要时整行平移，全部同一拍 560ms。连点从当前在播位置接走。Recents 不可选时只出 Toast。

  • 2

    拖 Filter：大小跟手、无缓动。松手 560ms 吸附。跨分组时角标 1 同步播。分割槽占位 60，跨槽一格 120。
