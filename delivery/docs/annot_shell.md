# 标注壳

用一份 HTML 原型同时交付 **机内界面** 和 **PRD / 交互与动效标注**。评审时打开交付物；关掉后手机居中，只剩产品本身。

参考实现：`delivery/01-ai-character/index.html`  
产品交接：`delivery/01-ai-character/docs/handoff.md`  
PRD / 动效原文：`delivery/01-ai-character/docs/prd.md` · `motion.md`  
叠层：`delivery/01-ai-character/docs/stacked_bottom_sheet.md`  
图标：[Lucide](https://lucide.dev)（ISC），内联 SVG，`currentColor`。勾用 Buz 字体 `\uE904`，不要再引别的图标字体。

本文只写壳。机内动效、字段规则走各自的 `prd.md` / `motion.md`。

令牌写在 `.studio` 的 CSS 变量上（`--s-*`），不要把壳的色和圆角写进 `.phone`。

---

## 1. 职责

| 壳负责 | 壳不负责 |
| --- | --- |
| 375 画板居中、左右栏 | 改产品视觉、文案、手势 |
| PRD 与交互与动效标注互斥展示 | 把标注画成 App 控件 |
| 编号角标、侧栏对照、可复制原文 | 用角标代替真实按钮 |
| 可选的内部探索（多版本） | 默认就把探索路径摊开 |

一次只开一种交付。PRD 讲「做什么」，交互与动效标注讲「怎么点、怎么动」。编号可以相同，**挂载点可以不同**。

## 2. 版式

整页 `#111`，Nunito。`.studio` 三列：

```
minmax(0, 1fr)   375px   minmax(0, 1fr)
左栏控制          手机     标注
```

| 区 | 规则 |
| --- | --- |
| 手机 | 永远在中间 375 列，不要为了让出标注把机身挪偏 |
| 左栏 `.studio-rail` | 宽 **240px**，高度随内容，相对屏幕垂直居中，贴左 |
| 标注 `.annot-col` | `≥1200px` 占右列并拉满剩余宽度；更窄时落到手机**下面**整行，内部滚动，高度约 `min(420px, 48vh)` |
| 页边距 | 上下 24、左右 48，列间距 24 |

右列不要锁死 320px。表格和卡片 `min-width: 0`，允许换行。

页角落（不进左栏）：固定左上，对齐页边距 24 / 48。箭头 + 上一页标题「设计与产品交付」。11 / 700 / `#4d4d4d`，hover `#808080`。不要做成第三项工具。

左栏从上到下：

1. **标题 + 开关**（在卡片外）  
2. **交付物卡**（总开关打开后才出现）  
3. 细分割线  
4. **设计探索**（弱一档，默认关）

不要用两个开关假装能同时开 PRD 和交互与动效标注。

## 3. 视觉令牌（仅壳）

字号只留 **11 / 13**，不要再给壳加 12 / 14 / 16 的字。16 只用于间距和卡片圆角。

### 3.1 字

| 角色 | 字号 | 字重 | 行高 | 字距 | 颜色 |
| --- | --- | --- | --- | --- | --- |
| 元信息、分组、文件名、操作、角标数字 | **11** | 400 或 700 | 1.3 | 1% | `#b3b3b3`；更弱 `#808080`；探索入口 `#4d4d4d` |
| 标题 / 选项 | **13** | 700 | 1.3 | 1% | `#fff`；勾 `#c4f353` |
| 右栏正文 | **13** | 400 | 1.45 | 1% | `#b3b3b3` |

角标数字例外：11 / **800**。

### 3.2 色

灰阶只用 Buz 四档，不要再造 `#0d0d0d` / `#161616` / `#e0e0e0` / IBM 紫 / 橙。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--s-page` | `#111` | 页底、角标挖白边 |
| `--s-well` | `#1a1a1a` | 分段槽、原文底、缩略框 |
| `--s-card` | `#292929` | 交付物卡、右栏卡片 |
| `--s-raise` | `#3d3d3d` | 选中滑块、分段 pill、动效角标底 |
| `--s-line` | `rgba(255,255,255,0.08)` | 分割线 |
| `--s-ink` | `#fff` | 主标题、未选项 |
| `--s-body` | `#b3b3b3` | 分组、正文 |
| `--s-dim` | `#808080` | 说明、工具条空闲 |
| `--s-quiet` | `#4d4d4d` | 设计探索入口 |
| `--s-lime` | `#c4f353` | **唯一强调色** |
| `--s-olive` | `#3b4525` | 左栏开关开态轨道 |

柠檬只用在：开关开态旋钮、选中勾、角标、行内图标、hover 外圈。选中行用 `--s-raise` 灰底，不要浅柠檬铺整行。不要再加蓝 / 橙当第二品牌色。

### 3.3 间距

| 用途 | 值 |
| --- | --- |
| 步进 | **4 / 8 / 12 / 16 / 24**（`--s-4` … `--s-24`） |
| 左栏块距 | 16；标题到卡 8；卡内垫 8 |
| 选项行 | 高 **40**，内边距 8 |
| 右栏卡片 | 表格/说明卡内边距 **16**；有编号列表的卡垫 **8**，选中行再垫 8。卡片间距 **12** |

### 3.4 圆角

| 用途 | 值 |
| --- | --- |
| 卡片 / 原文 / 缩略框 | **16**（`--s-radius`） |
| 卡内选中行、滑块 | **8**（`--s-nested`） |
| 胶囊（分段、演示） | **100**（`--s-pill`） |
| 角标 / 开关旋钮 | **正圆** |
| 开关轨道 | **15**（产品件，高 30 的一半） |

嵌套必须同心：`R内 = R外 − padding`。卡 16、垫 8，行只能是 8，**不能内外都是 16**。

### 3.5 开关（左栏）

产品 Controls/Switch，48×30，不要做成整条亮绿 + 白钮的 iOS 开关。

| 态 | 轨道 | 旋钮 |
| --- | --- | --- |
| 开 | `#3b4525` | `#c4f353`，直径 20，靠右 |
| 关 | `#3d3d3d` | `#fff`，靠左 |

旋钮走 **18px**、280ms。左栏开关不要 `:focus` 白描边。`.annot-mode` 和分段按钮必须 `background: transparent` + 自写字色，并给 `.annot-thumb` 铺 `--s-raise`。缺任一条都会露出系统白底按钮、黑字。

### 3.6 焦点

壳控件 `:focus-visible`：2px `#fff`，offset 2。开关除外。

## 4. 标注模式

交付物是 **Wi‑Fi 式**：先开总开关，打开后再选类型。点当前项不要关掉。

```
PRD 与标注  [Switch]
┌─────────────────────┐
│ PRD              ✓  │
│ 交互与动效标注        │
└─────────────────────┘
────────────
设计探索
```

- `PRD` 与 `交互与动效标注` 互斥  
- 左栏选项 `white-space: nowrap`，不要折行  
- 进页默认打开并选中 **PRD**；关掉总开关：右栏和角标收起；再打开回到**上次**那一项  
- 选中项：滑块 `#3d3d3d`（圆角 8）+ 文案 `#fff` + 勾 `#c4f353`  
- 滑块用 `.annot-thumb` 跟到目标行，不要给按钮铺灰底  
- `Esc` 先关机内层，再拨掉总开关（记住上次类型）

`#studio` 状态类：

| 类 | 含义 |
| --- | --- |
| `is-prd` | 需求文档 |
| `is-spec` | 交互与动效标注 |
| `is-annot` | 上两者任一（播壳动画、显示右栏） |
| `is-explore` | 设计探索打开（与交付物独立） |
| `is-ready` | 首屏量完滑块后再开过渡，避免进页闪一下 |

地址栏（`history.replaceState`，不要刷新）：

| 参数 | 作用 |
| --- | --- |
| （无参数） | 进页打开交付物并选中 PRD |
| `?annot=prd` / `?annot=spec` | 进页即开对应交付 |
| `?explore=1` 或 `#explore` | 打开设计探索 |

## 5. 编号角标

机内绝对定位；右栏用 `--inline`。

```html
<span class="prd-mark">2</span>                 <!-- 仅 PRD -->
<span class="spec-mark">2</span>                <!-- 仅交互与动效 -->
<span class="prd-mark spec-mark">1</span>       <!-- 两边同一控件 -->
<span class="prd-mark prd-mark--inline">2</span>
```

```css
.studio.is-prd .prd-mark { /* 可见 */ }
.studio.is-spec .spec-mark { /* 可见 */ }
```

不要用 `is-annot` 一把全开。编号序列彼此独立，不必对齐。

| 套 | 外观 |
| --- | --- |
| PRD | 实心柠檬，字 `#111` |
| 交互与动效 | 灰底 `#3d3d3d`，柠檬描边和数字 |

同一节点挂两套 class 时，跟当前 `#studio` 模式切换外观。

### 5.1 挂载

角标贴在控件**外侧角**（约 `top/right: -4px`）。圆角裁切的控件外包 `.mark-hit` 或 `.ai-refine-hit`。

**`data-hot` 必须挂在包住角标的那层**（`.mark-hit`），不要只挂在内部按钮上。角标是按钮的兄弟时，按钮 `.is-hot` 套不到角标，机内看不到外圈。Show more 的 `data-hot="5"` 挂在 `.mark-hit--more` 上，不要挂整张文本卡。

AI Refine 收起时（无 `.is-visible`）机内 2 / 6 角标一起藏，避免漂在正文上。

本页挂点：

| # | PRD | 交互与动效 |
| --- | --- | --- |
| 1 | Edit Character | 同左（叠层打开） |
| 2 | AI Refine | —（Toast 是系统组件，不打角标） |
| 3 | Save | —（关闭叠层存历史，不打角标） |
| 4 | Delete Character 行 | —（确认弹窗是系统组件，不打角标） |
| 5 | — | Show more（短文无角标） |
| 6 | — | AI Refine 按钮进出 |
| 7 | — | Description / Style 文本框（润色后高度） |

系统 Toast / 弹窗 / 关闭叠层参数写在 `motion.md` 的「历史」，不要打角标。

双 class 的 rest 描边比 hover 更具体，hot 规则必须写 `.studio.is-prd [data-hot].is-hot .prd-mark.spec-mark`，否则 1 没有外圈。

### 5.2 对照联动

机内、右栏条目、缩略图共用 `data-hot="N"`。同一节点可写多个编号（如 `data-hot="2 6"`），**只认当前交付物右栏里出现过的编号**：开 PRD 时 2，开交互与动效时 6。

悬停任一侧，对应节点加 `.is-hot`：

- 机内角标 scale 1.12，外圈 `2px #111` + `5px #c4f353`  
- 右栏 `.prd-rule` `--s-raise` 灰底，行内角标套柠檬圈；不要浅柠檬铺整行  

**钉住只点右栏 `.prd-rule`**。再点一次取消。机内只悬停联动，单击不要钉住。从机内悬停时，右栏 `scrollIntoView({ block: 'nearest' })` 到对应 `.prd-rule`。点右栏且存在 `data-hot-target` 时，滚到缩略图。缩略图只是示意，不要做成可点状态机。切 PRD / 交互与动效时清掉钉住和悬停。

瞬态控件在右栏加 `.prd-rule-actions`：复制、演示都是 **20px** 正圆纯图标（与行内角标同大），默认 `--s-dim`，不要绿色。复制成功换成石灰勾约 1.4s。复制取当前条目在 `prd.md` / `motion.md` 里对应的 `## N` 段落（没有标题则退回编号列表句）。点击复制或演示不要触发钉住。

`.prd-rule` 圆角用 `--s-nested`（8），不要 16。卡片垫 8，选中行贴在卡内。

`.prd-rule` 里角标、文案、按钮顶对齐（`align-items: flex-start`），跟第一行文字齐。

## 6. 右栏内容

`#annot-col` > `.annot-inner` > `#prd-panel` / `#spec-panel`。两块叠在同一 grid 格，靠透明度切换，不要 `display:none`。

每侧三层：

1. **可复制原文**（`prd.md` / `motion.md`）— 默收起  
2. **卡片对照** — 编号列表  
3. **PRD 可加分支缩略图** — Working / Disabled / Confirm 等  

原文给人拷，卡片给人扫，重复是故意的。

### 6.1 Markdown 条

```
prd.md  展开  复制
```

- 文件名不是按钮；和操作都是 **11 / 700**、`#808080`  
- hover / 展开中改白；已复制 `#c4f353`  
- 未展开也能复制；展开后「收起」，箭头旋转  
- `position: sticky; top: 0`  
- 复制改 `[data-copy-label]`，不要 `textContent` 整颗按钮  
- 高度 `grid-template-rows: 0fr → 1fr`，子项 `min-height: 0`

## 7. 壳动效

比叠层 sheet **更短**。不要用 420ms 开右栏。

长曲线 `cubic-bezier(0.32, 0.72, 0, 1)`，短曲线 `cubic-bezier(0.25, 0.72, 0.22, 1)`。

| 动作 | 位移 | 时长 |
| --- | --- | --- |
| 右栏进（宽屏） | X **16px** | **280ms** |
| 右栏进（窄屏） | Y **10px** + 高度 0fr→1fr | 高度 360 / 淡入 280 |
| 角标出现 | scale **0.84 → 1** | **220ms** |
| 面板互换 | 闲置面板 `position: absolute` 不占高；新面板 Y **8px** 淡入 | 淡入 240 / 位移 280 |
| Markdown / 探索 / 交付物卡 | 高度 0fr→1fr，Y **-6px** | 320 / 220–280 |
| 选中滑块 | 跟到目标行 | **280ms** |
| 勾 | 0.84→1 | **220ms** |
| 开关旋钮 | X **18px** | **280ms** |

关：先播完再 `visibility: hidden`（`visibility 0s linear <时长>`）。  
`prefers-reduced-motion: reduce` 时壳动画全部关掉。

宽屏右栏不要 `display:none`；左右垫 **16**，细滚动条。`annot-inner` `scroll-padding-top: 36px`，避免 sticky 工具条挡住锚点。窄屏用 0fr 收高度。进页加 `is-ready` 后再开过渡。

## 9. 脚本约定

壳逻辑单独 IIFE，不要和机内手势搅在一起。

| 钩子 | 用途 |
| --- | --- |
| `window.setStudioAnnotMode('prd' \| 'spec' \| '')` | 机内 `Esc` 链最后关标注 |
| `window.playAnnotToastDemo()` | 按需 |
| `window.playAnnotShowMoreDemo()` | 右栏「演示」Show more |
| `window.playAnnotRefineAppearDemo()` | 右栏「演示」Refine 进出：框高 280ms 补间，按钮只做透明度和缩放 |
| `window.playAnnotRefineGrowDemo()` | 右栏「演示」润色后框高：400ms 换文再还原 |

进页先读 `annot` / `explore`，再 `replaceState` 写回。滑块在 `resize`、`transitionend`、模式切换后重新测量。

## 10. 新原型怎么套

1. 拷 `.studio` 三列、左栏 Wi‑Fi 结构、`#annot-col`、角标与 `data-hot`。令牌用 `--s-*`。  
2. 中间只放自己的 375 画板。  
3. PRD 编号打在**能看见的控件**上；动效编号打在**产生该动效的表面**上。系统 Toast / 弹窗不打角标。  
4. `data-hot` 挂在 `.mark-hit` 上，角标放在同一层里。  
5. 两份 `<pre id="prd-md">` / `<pre id="spec-md">`，进页 `dedent`。  
6. 会瞬态出现的加 `.annot-demo`。  
7. 检查：关标注后机身仍居中、无角标、无右栏；开标注后原文默收；悬停 Edit 机内角标有柠檬外圈；分段选中白字在深灰 pill 上；卡内选中行圆角是 8 不是 16。  

不要把壳的角标、分段、探索入口带进 App 视觉。关掉壳之后，屏幕上应只剩产品。左上「设计与产品交付」仍可回落地页。
