# AI Character 资料与编辑

原型：`delivery/01-ai-character/index.html`  
默认打开本 PRD。交互与动效在左侧切到「交互与动效标注」。

本文是按当前原型整理的草稿。产品补全边界、文案和未做规则；动效数字不要写进这里。

## 待产品补

- 入口：从哪里进、谁能看/编辑/删除
- 编辑中为何不可删除；退出编辑未保存是否丢改动
- AI Refine：要不要二次确认、失败/取消、是否进主路径 Hold original
- Avatar 本迭代是否可换
- 空态、超字数、网络失败的文案
- Toast / 确认框文案是否定稿（系统组件，设计侧不改样式）

## 触发条件

从会话列表点开某个 AI 角色，进入本资料页。资料以 bottom sheet 盖在会话之上。

- 编辑中不可删除
- 删除仅资料页可点

## 字段定义

| 字段 | 规则 |
| --- | --- |
| Name | 必填。空则 Save 不可点。 |
| Description | 必填，最多 1000。空则隐藏 AI Refine。 |
| Speaking style | 必填，最多 600。规则同 Description。 |
| Avatar | 本原型不换图。Change Avatar 为占位。 |

## 交互规则

1. **Edit Character** — 打开编辑层。
2. **AI Refine** — 字段有字才显示。确认后出 Working toast，完成后替换当前字段并出成功 toast。
3. **Save** — Name / Description / Style 任一为空，或正在 Refine，Save 置灰。成功则写回资料页并收起编辑层。
4. **Delete** — 二次确认后资料 sheet 下滑离场，toast「Character deleted.」

## 分支状态

- Working toast
- Save disabled
- Delete confirm
- Empty field

# 交互与动效

只标业务动效。Toast / 确认弹窗是系统组件，不打角标，本期不改。

机内角标：

| # | 表面 | 这条动效 |
| --- | --- | --- |
| 1 | Edit Character | 打开编辑叠层 |
| 5 | Show more | 资料卡正文高度 |
| 6 | AI Refine | 按钮随框高进出 |
| 7 | Description / Style 文本框 | 润色后框高跟着正文变 |

2、4 是系统 Toast / 确认框，不标。关闭叠层原先是 3，改存历史，不打角标。

---

## 共用

叠层、Show more、Refine、键盘、按压都走同一条曲线，不要用 560ms（那是 VE-Tab）。

| | |
| --- | --- |
| 曲线 | `cubic-bezier(0.32, 0.72, 0, 1)` |
| 叠层时长 | **420ms** |
| 错开 | **80ms**，只用于打开：下层立刻、上层晚 80ms。关闭两层一起动 |
| Sheet 原点 | `transform-origin: 50% 0`（顶中） |

---

## 1 · 打开叠层

触发：资料页点 Edit Character。

| 层 | 何时动 | 做什么 |
| --- | --- | --- |
| 下层（资料） | 立刻，无 delay | `translateY(-10px) scale(335/375)`；顶角 30→20；底 `#1a1a1a`→`#141414`；handle 隐；内容 opacity 65% |
| 上层（编辑） | 晚 **80ms** | `translateY(100%) → 0`，满宽滑入 |
| 露出 | 到位后 | 下层顶边露出 **10px**，可点关闭 |

不要 `scaleX`。不要用纯色块假装缩小。下层内容还在，只是被挡住。

---

## 5 · Show more

触发：资料页 Description / Style 正文超过 **6 行**。短文没有入口，也不要占位。

| | |
| --- | --- |
| 动什么 | 只动画正文 `height` |
| 时长 | **360ms**，叠层同一条曲线 |
| 文案 | Show more ↔ Show less |
| 不要 | 不要改 opacity；不要瞬间改 `line-clamp` |

---

## 6 · AI Refine 进出

触发：字段从空到有字（或反过来）。扫描 / 骨架进行中要藏。

框高用 280ms 补间；按钮只做透明度和缩放。不要只动画按钮 `max-height`，否则框高量不准、按钮会压住正文。

| | 隐 | 显 |
| --- | --- | --- |
| 框高 | 收掉按钮占位 | 让出按钮高度 |
| 按钮 opacity | 0 | 1 |
| 按钮 scale | 0.82，原点左中 | 1 |
| 占位（瞬时切入补间） | max-height 0 · margin 0 · padding 0 8px | 32 / 10 / 4px 8px |
| 时长 | **280ms**，叠层同一条曲线 | |

有字才显示。

---

## 7 · 润色后框高

触发：AI Refine 完成、新文案写进字段。正文变长或变短，**整个文本框**用 height 补间跟上，不要瞬间撑开、也不要只拉 textarea 不带动框。

和 6 不是同一条：6 是空↔有字时按钮进出；7 是润色替换正文后的框高。打字时框高可以瞬时跟上，不必走这条。

| | |
| --- | --- |
| 动什么 | `.textarea-box` 的 `height`（先量旧高，换文，再补间到新高） |
| 时长 | **400ms**，叠层同一条曲线 |
| 补间中 | `overflow: hidden`，结束后解开 |
| 不要 | 不要改 opacity；高度差 < 1px 则跳过动画 |

V1 主路径在 Working toast 到 100% 时走这条。探索 V2 出骨架 / 换文时同一套 400ms。

| 收起 | Return / 点空白处 |

## 按压（不打角标）

时长 **120ms**，叠层同一条曲线。

| 控件 | scale |
| --- | --- |
| Edit Character | 0.97 |
| Close | 0.88 |
| Save | 0.96 |
| 文本卡 | 0.985 |
| 清除 | 160ms 显隐，focus 时才出现 |

---

## 系统组件（不打角标）

本期不改。实现仍走现有 Toast / 确认弹窗。

Toast：220ms · `cubic-bezier(0.25, 0.72, 0.22, 1)` · 只 Y 8px · 字和图标淡入淡出 · 玻璃底 0→0.78（不要给整层加 opacity）· Working 到 100% 再持 160ms · 成功文案停 2200ms。

确认框：遮罩 70% · 卡 335 / 圆角 40 / `#1f1f1f` · 280ms · Y 10 + scale 0.96→1。删角色后资料 sheet `translateY(100%)`，420ms 叠层曲线。

---

## 历史 · 关闭叠层

原先角标 3，本期不打。X / Save / 10px 顶边 / 跟手超阈值仍走同一条，不要瞬切。

| 层 | 何时动 | 做什么 |
| --- | --- | --- |
| 上层 | 立刻 | `translateY(100%)` 下滑 |
| 下层 | 立刻 | 还原满宽、顶角 30、底 `#1a1a1a`、handle 和内容透明度。不要晚 80ms |
| 父层 | 等 **420ms** | 再 `visibility: hidden` |

跟手：拖时关掉 transition。松手 **dy > 90px** 或 **vel > 0.85** 则关闭，否则弹回。
